# 2D-MatAgent 阶段路线图

表中阶段是项目的八个开发阶段。历史文档中的“第 12 步”指机器学习势工作流的一次端到端验收，覆盖本表前半段。

| 阶段 | 当前状态 | 完成标志与证据 |
|---|---|---|
| 0 · 仓库与架构 | 已完成 | 已梳理 MatSimPy、UniMatSim 的可复用接口，形成[架构说明](architecture.md)与[能力清单](capabilities.md)。 |
| 1 · 最小 Agent | 已完成 | 中文终端可对话、选择工具、执行查询和恢复会话。[会话验收](conversations.md) |
| 2 · 接入 MatSimPy | 已完成 | 用户可基于有来源的原型建立单层结构，经工具编辑、保存并作为后续任务输入。[结构建模](structures.md) |
| 3 · 接入 UniMatSim | MatterSim CPU 主流程已验收 | 单层 MoS₂ 优化后，单点与结构分析节点均收到优化结构。MACE 已有参数映射，真实权重计算仍待单独验收。[自然语言验收](acceptance.md)、[势模型覆盖](potentials.md) |
| 4 · 2D-PhysicsGuard | 基础版已验收 | 已覆盖固定晶胞二维样例的输入检查、收敛判据及缺失证据。更广泛的结构合理性判断需新增材料与反例验证。[检查规则](physics_guard.md) |
| 5 · VASP / Slurm | 有结果提取配置入口，完整流程待开发 | VASP 结果提取的实跑状态见[执行覆盖表](execution.md)。阶段验收要求从结构准备 DFT 输入、获得明确审批、提交 Slurm 作业、跟踪状态并读回同一作业的结果。 |
| 6 · 自主筛选闭环 | 待开发 | 能依据有来源的 DFT 结果选择下一次候选或任务，保存选择依据、停止条件和计算记录。 |
| 7 · 高通量材料应用 | 待开发 | 在经确认的 MXNH 与九原子层候选集上完成可复现的批量研究，并能追溯候选来源、计算和筛选结论。 |

各阶段按[开发约定](../AGENTS.md)独立验收。进入阶段 5 前，需要先核对目标集群实际可用的 VASP 与 Slurm 接口。
